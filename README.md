# Console task lifecycle captures (hk 3340)

Every image is the committed production bundle rendered against fictional
same-origin responses (task 107 for the dialogs, task 102/107 rows). No host,
account or address is real.

- `row-menu-*`: the work row action menu with all registry entries; disabled
  entries carry their Korean reason.
- `close-merged-*`: the close-as-merged dialog on a developing task; evidence
  is prefilled from the task's PR and the path shows 개발 중 → 검토 중 → 머지됨.
- `drop-dialog-*`: the drop/duplicate dialog with 대체됨 selected and the
  surviving task id filled in.
- `relane-picker-*`: the lane picker on the task record; the current lane is
  excluded.

Each view is captured at 1440 and 390, dark and light.
